# java-explore-with-me

## Реализована дополнительная функциональность "Комментарии"

Зарегистрировавшийся пользователь может оставить к опубликованному событию свой комментарий, который после этого должен
одобрить администратор. Только опубликованные комментарии видны с публичных эндпоинтов.
